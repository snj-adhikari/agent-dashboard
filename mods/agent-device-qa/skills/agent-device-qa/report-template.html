Real Android phone

USB + Chrome remote debugging

  1. Phone: Settings ▸ About ▸ tap Build number 7 times. Developer options ▸ USB debugging on.
  2. Plug in, tap Allow on the phone. Check: adb devices shows device.
  3. adb reverse tcp:{{APP_PORT}} tcp:{{APP_PORT}}, then open http://localhost:{{APP_PORT}}/… in phone Chrome.
  4. Laptop Chrome ▸ chrome://inspect ▸ Inspect the phone tab ▸ Console ▸ paste the logger.
  5. Screenshot: adb exec-out screencap -p > shot.png.
  6. Automated: adb forward tcp:9333 localabstract:chrome_devtools_remote + agent-browser --cdp 9333, taps via adb shell input tap.
iPhone simulator

Xcode Simulator + Safari

  1. Xcode ▸ Settings ▸ Components ▸ install an iOS runtime (~8.5 GB). Open Simulator, pick an iPhone.
  2. Open http://localhost:{{APP_PORT}}/… in simulator Safari (it shares the Mac's network).
  3. Mac Safari ▸ Develop ▸ Simulator ▸ the page ▸ Console ▸ paste the logger.
  4. Screenshot: xcrun simctl io booted screenshot shot.png.
  5. Automated: a local proxy added the logger and a click runner to each page; results posted back.
Safari on Mac

Safari Web Inspector

  1. Safari ▸ Settings ▸ Advanced ▸ "Show features for web developers".
  2. Open the page, Develop ▸ Show Web Inspector ▸ Console ▸ paste the logger.
  3. Scripted runs: the same local proxy, or sudo safaridriver --enable for WebDriver.
Real iPhone

USB + Web Inspector

  1. iPhone: Settings ▸ Apps ▸ Safari ▸ Advanced ▸ Web Inspector on.
  2. Plug in, trust the Mac. Mac Safari ▸ Develop ▸ your iPhone ▸ the page ▸ Console.
  3. Phone reaches the laptop on the same Wi-Fi: http://<laptop-ip>:{{APP_PORT}}.
