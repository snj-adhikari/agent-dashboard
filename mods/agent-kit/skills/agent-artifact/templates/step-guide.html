GA4 MCP Prompt Kit

Connect Claude Code to your GA4 properties with Google's Analytics MCP server, read-only, then ask questions in plain English.

Quickest way: let Claude guide you

Paste this into Claude Code. It walks you through every step below and uses Claude in Chrome to show you where to click in Google Cloud and GA4.

Setup prompt
Help me set up Google's Analytics MCP server (analytics-mcp) in Claude Code with read-only access. First check whether I'm on macOS or Windows and give every command in the right form for my OS (on Windows use PowerShell, and paths like C:\Users\ME\AppData\Roaming\gcloud\...). Go one step at a time, give me each command to run myself, and wait for me before moving on.

0. Check whether Claude in Chrome is connected (/chrome). If it isn't, help me set it up first: install the Claude in Chrome extension from the Chrome Web Store, sign in with my Claude account, then run /chrome and enable it. Use it to guide me in the browser in later steps (open the right page, point out what to click). Don't change any settings in Google Cloud or GA yourself.
1. Check gcloud, pipx and Python 3.10+ are installed. If not, install them (Mac: brew install --cask google-cloud-sdk and brew install pipx; Windows: winget install Google.CloudSDK, winget install Python.Python.3.12, then py -m pip install --user pipx and py -m pipx ensurepath, and reopen the terminal).
2. Use Chrome to open GA4 Admin > Property access management and confirm I have the Viewer role on the properties you need.
3. Enable the APIs: gcloud services enable analyticsadmin.googleapis.com analyticsdata.googleapis.com --project=YOUR_PROJECT_ID
4. Log in with read-only GA access (gcloud also requires cloud-platform):
   gcloud auth application-default login --scopes="https://www.googleapis.com/auth/analytics.readonly,https://www.googleapis.com/auth/cloud-platform"
   gcloud auth application-default set-quota-project YOUR_PROJECT_ID
   If sign-in says access is blocked, help me create a Desktop OAuth client in Google Cloud Console and log in again with --client-id-file.
5. Register the server with the absolute credentials path gcloud printed, then check claude mcp list shows it Connected:
   claude mcp add analytics-mcp --scope user -e GOOGLE_APPLICATION_CREDENTIALS="ABSOLUTE_PATH" -e GOOGLE_CLOUD_PROJECT="YOUR_PROJECT_ID" -- pipx run analytics-mcp
6. After I restart Claude Code, call get_account_summaries and list the GA4 properties it can see.

The flow

Read-only: GA access is analytics.readonly, so Claude can read reports and settings but can't change anything in GA.

Step by step

  1. 1
    You, once

    Check access and tools

    GA4 Viewer on the properties you need, plus gcloud, pipx and Python 3.10+ installed. Optional: Claude in Chrome, so Claude can guide you in the browser.

    Check (Mac)
    gcloud --version
pipx --version
python3 --version
    Install if missing (Mac)
    brew install --cask google-cloud-sdk
brew install pipx
pipx ensurepath
    Check (Windows, PowerShell)
    gcloud --version
pipx --version
py --version
    Install if missing (Windows, PowerShell)
    winget install Google.CloudSDK
winget install Python.Python.3.12
py -m pip install --user pipx
py -m pipx ensurepath
# then close and reopen PowerShell
    Show prompt
    Check whether gcloud, pipx and Python 3.10+ are installed on my machine (detect macOS or Windows). Give me the install commands for anything missing, for my OS, and let me run them myself.
    Set up Claude in Chrome
    Check whether Claude in Chrome is connected. If not, walk me through it: install the Claude in Chrome extension from the Chrome Web Store, sign in with my Claude account, then run /chrome in Claude Code and enable it. Confirm by listing my open Chrome tabs.
  2. 2
    Once per Google Cloud project

    Enable the APIs

    Skip if someone has already done it on the project.

    Show command
    gcloud services enable analyticsadmin.googleapis.com analyticsdata.googleapis.com --project=YOUR_PROJECT_ID
    Show prompt
    Check whether the Google Analytics Admin API and Data API are enabled on Google Cloud project YOUR_PROJECT_ID. If they aren't, give me the gcloud command to enable them and let me run it myself.
  3. 3
    You · opens a browser

    Log in read-only

    Sign in with your work Google account and note the credentials path it prints. gcloud insists on the cloud-platform scope too; GA access stays read-only. Google's auth guide

    Show command
    gcloud auth application-default login --scopes="https://www.googleapis.com/auth/analytics.readonly,https://www.googleapis.com/auth/cloud-platform"
gcloud auth application-default set-quota-project YOUR_PROJECT_ID
    If Google blocks the sign-in
    # Google is phasing out analytics.readonly on gcloud's built-in client.
# If sign-in shows "access blocked", create a Desktop OAuth client in
# Google Cloud Console > APIs & Services > Credentials, download the JSON, then:
gcloud auth application-default login --client-id-file=PATH_TO_CLIENT_JSON --scopes="https://www.googleapis.com/auth/analytics.readonly,https://www.googleapis.com/auth/cloud-platform"
    Show prompt
    Help me log in to Google for the Analytics MCP server with read-only GA access. Give me the gcloud application-default login command for my OS with the analytics.readonly and cloud-platform scopes, then set the quota project to YOUR_PROJECT_ID. If sign-in says access is blocked, walk me through creating a Desktop OAuth client in Google Cloud Console (use Claude in Chrome to show me where) and logging in with --client-id-file. Tell me the full path of the credentials file at the end.
  4. 4
    You · Claude Code

    Add the server

    Use the full credentials path from step 3, not ~. Restart Claude Code afterwards.

    Show command (Mac)
    claude mcp add analytics-mcp --scope user -e GOOGLE_APPLICATION_CREDENTIALS="/Users/YOU/.config/gcloud/application_default_credentials.json" -e GOOGLE_CLOUD_PROJECT="YOUR_PROJECT_ID" -- pipx run analytics-mcp
    Show command (Windows, PowerShell)
    claude mcp add analytics-mcp --scope user -e GOOGLE_APPLICATION_CREDENTIALS="$env:APPDATA\gcloud\application_default_credentials.json" -e GOOGLE_CLOUD_PROJECT="YOUR_PROJECT_ID" -- pipx run analytics-mcp
    Show prompt
    Add Google's Analytics MCP server to Claude Code at user scope: claude mcp add analytics-mcp --scope user, with GOOGLE_APPLICATION_CREDENTIALS set to the full path of my gcloud application default credentials file and GOOGLE_CLOUD_PROJECT set to YOUR_PROJECT_ID, running pipx run analytics-mcp. Use the right path format for my OS, then run claude mcp list and confirm it shows Connected.
  5. 5
    Claude Code

    Check it works

    A 403 ACCESS_NOT_CONFIGURED means the quota project isn't set: rerun the second line of step 3.

    Show prompt
    Using the GA MCP, list the GA4 accounts and properties I can access.
